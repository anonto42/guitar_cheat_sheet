# Mobile apps

Three ways to use the app on a phone, all from the same codebase.

## 1. Installable web app (PWA)
`app/manifest.ts` and the service worker make the site installable from Chrome, Edge and Safari. The `/download` page shows an Install button when the browser offers one, and Add to Home Screen steps on iOS.

## 2. Android app (Capacitor)
The site is exported as static files (`npm run build:mobile`, output in `out/`) and wrapped in a native WebView. The full library is inside the APK, so it works offline from the first launch.

What is in the repository:
- `android/`: the native project generated by Capacitor 8 (app id `com.guitarcheatsheet.app`, minimum Android 7, target Android 16).
- Microphone permission (`RECORD_AUDIO`) for the tuner and recording. Android asks the player the first time they press Start tuner or Record.
- Launcher icons and splash screens generated from `public/favicon.svg` (`npm run generate-icons`, then `npx @capacitor/assets generate --android`).
- `features/install/NativeBootstrap.tsx`: status bar colour, splash screen and the Android back button.

### Getting the APK (no Android Studio needed)
`.github/workflows/android.yml` builds it on GitHub:
- Push a tag such as `v1.0.0`: the workflow builds a release APK and attaches `guitar-cheat-sheet.apk` to a GitHub Release. The Android button on `/download` always points at the latest release.
- Or run the workflow by hand from the Actions tab to get the APK as a build artifact.

### Signing
Set these repository secrets so every release is signed with the same key (needed for updates to install over an older version):

| Secret | Value |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | `base64 -w0 release.keystore` |
| `ANDROID_KEYSTORE_PASSWORD` | keystore password |
| `ANDROID_KEY_ALIAS` | key alias |
| `ANDROID_KEY_PASSWORD` | key password |

Create a key once with:
```bash
keytool -genkeypair -v -keystore release.keystore -alias guitarcheatsheet -keyalg RSA -keysize 2048 -validity 10000
```
Keep the keystore file and passwords safe and never commit them. Without the secrets the workflow still builds an installable APK signed with a temporary debug key and prints a warning.

### Building locally
Needs Node 22 (Capacitor 8), JDK 21 and the Android SDK (Android Studio installs both).
```bash
npm run cap:sync            # static export + copy into android/
npm run cap:open:android    # open in Android Studio, press Run
npm run cap:build:android   # or build the release APK from the command line
```
`scripts/build-mobile.mjs` moves `app/og` aside during the export (image generation needs a server) and always restores it.
