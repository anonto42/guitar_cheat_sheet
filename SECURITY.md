# Security policy

## Reporting a vulnerability
Please do not open a public issue for security problems. Use GitHub's "Report a vulnerability" button under the Security tab of the repository. Include steps to reproduce and the affected version or commit.

You can expect an acknowledgement within 5 working days and a fix or mitigation plan within 30 days for confirmed issues.

## Scope
The web app, the service worker and the Capacitor native shell. The site stores no accounts and no personal data; user presets for GuitarFX stay in the browser's local storage.
